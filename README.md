# Zepto-Retail-Inventory-Pricing-Analysis-using-SQL

📌 1. Project Overview :
This project focuses on analysing Zepto's retail product and inventory dataset using PostgreSQL. The objective is to explore product pricing, discounts, stock availability, and category-wise inventory to derive meaningful business insights.
Using SQL queries, I performed data exploration, data cleaning, and analysis to understand product distribution, pricing patterns, discount strategies, and inventory levels.

🎯 2. Project Purpose :
The purpose of this project is to demonstrate practical SQL skills by working with a retail dataset and solving business-related analytical questions.
The analysis aims to identify pricing trends, evaluate discount patterns, examine stock availability, and understand inventory distribution across different product categories.

🛠️ 3. Tools & Technologies :
* Database: PostgreSQL
* SQL Environment: pgAdmin 4
* Dataset: Zepto Retail Product Dataset (CSV)
* Language: SQL

📂 4. Dataset Information :
The dataset contains 3,732 product records and 9 original columns describing product categories, pricing, discounts, stock availability, and product weights.

🔍 5. Business Questions & SQL Analysis :
The project addresses the following business questions using SQL:

1. Top Discounted Products: Identify the top 10 products offering the highest discount percentages.
2. Out-of-Stock Products: Find products that are out of stock and have an MRP greater than ₹300.
3. Category-wise Inventory Value: Calculate the estimated inventory value for each product category using discounted selling price and available quantity.
4. High-MRP, Low-Discount Products: Identify products with an MRP greater than ₹500 and a discount percentage below 10%.
5. Category-wise Average Discount: Find the top 5 product categories offering the highest average discounts.
6. Price per Gram Analysis: Calculate the price per gram for products weighing at least 100 grams to compare their relative pricing.
7. Product Weight Categorisation: Classify products into Low, Medium, and Bulk weight categories using SQL CASE statements.
8. Category-wise Inventory Weight: Calculate the total inventory weight available in each product category.

📚 6. Key Learnings :

Improved understanding of data exploration and cleaning techniques.
Learned to apply aggregate functions and grouping to answer business questions.
Used SQL calculations to analyse product pricing, discounts, and inventory.
Developed the ability to translate business requirements into SQL queries.

🏁 7. Conclusion :
This project demonstrates how SQL can be used to transform raw retail data into meaningful business insights. Through data cleaning, exploratory analysis, and business-oriented queries, the project provides a structured view of product pricing, discount strategies, and inventory distribution.
It strengthened my practical understanding of PostgreSQL and its application in solving real-world data analysis problems.
